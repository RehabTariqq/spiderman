# Spider-Man Contour Tracer

An animated image tracing project built with Python, OpenCV, and Turtle Graphics.

The program processes a Spider-Man image, detects its contours using OpenCV, and redraws the detected contours using Turtle Graphics.

## Technologies

- Python
- OpenCV
- Turtle Graphics
